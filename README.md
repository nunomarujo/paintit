# Paint it

Marketplace de orçamentação e contratação de empreitadas de pintura em Portugal (nome provisório).

- Condomínios e particulares descrevem a obra e recebem propostas comparáveis.
- Pintores verificados orçamentam sem ver morada nem contactos.
- O cliente escolhe, deposita uma garantia e assina; o pintor paga a comissão e assina.
- A plataforma retira-se quando o contrato está assinado.

## Começar

```bash
npm install
npm run dev     # http://localhost:3000
npm test
```

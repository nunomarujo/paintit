# taste-skill — capítulos adoptados (01/11/2026)

Cópia dos capítulos de referência do [taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT, licença
ao lado) que regem o desenho de ecrãs da aplicação Quem Pinta. O promotor pediu-o a 01/11/2026 por os
ecrãs parecerem «templated» e todos iguais. A regra 19 do `CLAUDE.md` obriga a lê-los antes de desenhar
ou rever um ecrã.

- `app-screens.md` — **o que manda aqui**: ecrãs em que se trabalha (listas, formulários, fichas,
  painéis). Ler inteiro antes de qualquer ecrã novo.
- `tells.md` — o registo dos sinais de página gerada e o que os substitui.
- `critique.md` — como olhar para uma captura e o que corrigir primeiro.
- `copy.md` — como escrever as palavras de um ecrã.

**Excepção declarada da Quem Pinta:** a barra lateral marinho (`#14213d`) com rótulo do perfil em lima,
decisão do promotor sobre maquete (01/11/2026). O guia proíbe barras escuras em ecrãs claros; aqui é
identidade de marca e mantém-se. Tudo o resto aplica-se.

Os scripts do repositório original (`draw.mjs`, `inspect.mjs`, `lint.mjs`) não foram copiados: precisam
de Node 22 e de um Chromium; quem os quiser correr clona o repositório e corre a partir do raiz do projeto.
